# Posters

ICT's own result and admission posters, as published on Instagram and Facebook.

1. Drop the image here (jpg, png or webp). Keep the original resolution.
2. Add a row to `posters` in `lib/brand.ts` with the filename, alt text and a
   caption describing only what the poster actually shows.
3. Check any result claim against the official result before adding it. Set
   `verified: true` only when it is checkable in a primary source.

The results section hides itself while there are no posters.
